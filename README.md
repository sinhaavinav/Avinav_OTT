# Avinav_OTT
This is a responsive front-end project for an OTT (Over-The-Top) streaming platform, designed to provide users with an engaging interface to browse, search, and watch their favorite movies, series, and shows. The project is built using modern web technologies like HTML5, CSS3, JavaScript, and frameworks/libraries like React.js (optional — depending on your project setup).

Features:
1. Landing Page: Eye-catching homepage with featured content and banners
2. Search Functionality: Search for movies, web series, and shows
3. Categories & Genres: Browse content by category (Action, Comedy, Drama, etc.)
4. Trending Section: Display of trending and recommended content
5. Video Player UI: Basic video player page design
6. User Authentication UI: (Optional) Sign Up / Login forms
7. Dark Mode: Optional dark/light theme toggle
8. Responsive Design: Fully responsive layout for mobile, tablet, and desktop
